# 스마트 화분 하드웨어 배선 체크포인트

- 마지막 정리: 2026-08-17
- 현재 단계: Raspberry Pi 4와 MCP3008 연결 중
- 전원 상태: **연결 금지 / 꺼진 상태 유지**

이 문서는 다른 작업 세션에서도 현재 배선 상태를 이어서 확인하기 위한 기록이다. 아래 내용은 대화와 사용자가 확인한 사진을 기준으로 정리했다.

## 사용 중인 핵심 부품

- Raspberry Pi 4 Model B
- MCP3008-I/P 아날로그-디지털 변환기(ADC)
- SEN0193 정전용량식 토양 수분 센서
- MB-102 830핀 브레드보드

## MCP3008 방향과 핀 번호

MCP3008의 동그란 점이 있는 모서리를 기준으로 핀을 센다. 현재 브레드보드에 놓인 방향에서는 다음과 같다.

- 동그란 점이 있는 쪽의 맨 위 왼쪽: 1번
- 왼쪽 줄은 위에서 아래로 1번부터 8번
- 오른쪽 줄은 아래에서 위로 9번부터 16번
- 따라서 동그란 점의 바로 맞은편 맨 위 오른쪽이 16번

## 지금까지 연결 완료

### Raspberry Pi에서 브레드보드 전원 레일

| Raspberry Pi | 선 색상 | 브레드보드 |
|---|---|---|
| 물리 1번, 3.3V | 빨간색 | 빨간 `+` 레일 |
| 물리 6번, GND | 갈색 | 파란 `-` 레일 |

### MCP3008

| MCP3008 핀 | 역할 | 선 색상 | 연결 위치 | 상태 |
|---|---|---|---|---|
| 16번 | VDD | 빨간색 | 빨간 `+` 레일 | 완료 |
| 15번 | VREF | 빨간색 | 빨간 `+` 레일 | 완료 |
| 14번 | AGND | 갈색 | 파란 `-` 레일 | 완료 |
| 13번 | CLK | 노란색 | Pi 물리 23번, GPIO11/SCLK | 완료 |
| 12번 | DOUT | 초록색 | Pi 물리 21번, GPIO9/MISO | 완료 |
| 9번 | DGND | 검은색 | 파란 `-` 레일 | 완료 |

## 다음에 할 일

순서대로 한 가닥씩 연결하고, 각 단계마다 사진으로 위치를 확인한다.

1. MCP3008 11번 DIN을 Pi 물리 19번(GPIO10/MOSI)에 연결
2. MCP3008 10번 CS를 Pi 물리 26번(GPIO7/CE1)에 연결
3. SEN0193 수분 센서 연결
   - VCC → 3.3V
   - GND → GND
   - Signal → MCP3008 1번 CH0
4. 전체 배선을 다시 확인한 뒤에만 전원 연결

## 전원 연결 전 안전 확인

- Raspberry Pi 전원이 완전히 분리되어 있는지 확인
- MCP3008의 동그란 점 방향과 핀 번호를 다시 확인
- 3.3V 선과 GND 선이 서로 닿지 않는지 확인
- 느슨하거나 한 칸 어긋난 점퍼선이 없는지 확인
- 금속 핀셋이나 드라이버 등 전기가 통하는 물건을 회로에서 치우기
- 사진으로 전체 연결을 최종 확인하기 전에는 전원을 켜지 않기

## 바로 이어서 할 단계

MCP3008 11번 DIN을 Raspberry Pi의 **물리 19번(GPIO10/MOSI)** 에 연결한다. 현재 사진과 같은 Raspberry Pi 방향에서는, 방금 연결한 초록색 DOUT 선의 물리 21번 바로 왼쪽 같은 줄이 물리 19번이다. 연결 후 Raspberry Pi GPIO 부분과 MCP3008 11번 부분이 함께 보이는 사진을 찍어 확인한다.

## 최근 확인 메모

- MCP3008 12번 DOUT의 초록색 선 반대쪽은 Raspberry Pi 물리 21번(GPIO9/MISO)에 연결 완료했다.
- 현재 사진과 같은 방향에서 물리 21번은 노란색 CLK 선이 연결된 물리 23번의 바로 왼쪽 같은 줄이다.
